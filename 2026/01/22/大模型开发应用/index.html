AIFriend项目实践

AIFriends

1.配置环境、创建导航栏

  1. 配置Pycharm (https://www.jetbrains.com/zh-cn/pycharm/)

  2. 配置git环境(https://gitforwindows.org/)

  3. 安装Node(https://nodejs.org/en/download)

  4. Pycharm中创建项目

  5. 安装后端(django)

django：Python 最主流的 Web 框架，提供了完整的 MVC（MTV）架构、ORM 数据库操作、表单验证、后台管理系统、安全防护等一站式 Web 开发能力，是整个项目的基础。

djangorestframework： Django 的 RESTful API 扩展库，是 Django 开发接口的事实标准。它在 Django 基础上封装了一套更简洁、更符合 REST 规范的 API 开发工具。

djangorestframework-simplejwt： DRF 的扩展库，专门用于实现 JWT（JSON Web Token）认证机制。

django-cors-headers： 解决跨域资源共享（CORS）问题。

补充：Diango默认：127.0.0.1:8000 (会和SpringBoot端口冲突，不要同时还启动SpringBoot即无问题)

​ Vue3末默认：localhost:5173

6.创建后端项目(backend文件夹放后端)

django-admin startproject backend（创建文件夹）
cd .\backend\ （进入backend目录）
django-admin startapp web（创建Web）
python manage.py migrate（同步数据库）
python manage.py createsuperuser（创建一个管理员）
python manage.py runserver（运行Django服务器）

补充：在生成的网址中加上/admin会跳转Django自带的管理员后台（我设置的账号:admin 密码：123456）

7.配置

注册app
INSTALLED_APPS = [
…
‘rest_framework’,
‘web’,
‘corsheaders’,
]

MIDDLEWARE = [
‘corsheaders.middleware.CorsMiddleware’, # 必须尽量靠前
…
]

设置成中国时区
TIME_ZONE = ‘Asia/Shanghai’

设置static和media静态文件路径
STATIC_URL = ‘static/‘

#STATIC_ROOT = BASE_DIR / ‘static’ # 生产阶段使用

STATICFILES_DIRS = [ # 开发阶段使用，生产阶段需要注释掉
BASE_DIR / ‘static’,
]

MEDIA_URL = ‘http://127.0.0.1:8000/media/‘
MEDIA_ROOT = BASE_DIR / ‘media’

使用JWT认证

from datetime import timedelta

REST_FRAMEWORK = {
‘DEFAULT_AUTHENTICATION_CLASSES’: (
‘rest_framework_simplejwt.authentication.JWTAuthentication’,
),
}

SimpleJWT配置

SIMPLE_JWT = {
‘ACCESS_TOKEN_LIFETIME’: timedelta(hours=2),
‘REFRESH_TOKEN_LIFETIME’: timedelta(days=7),

'ROTATE_REFRESH_TOKENS': True,
'BLACKLIST_AFTER_ROTATION': True,

'AUTH_HEADER_TYPES': ('Bearer',),

}

配置跨域

CORS_ALLOW_CREDENTIALS = True

CORS_ALLOWED_ORIGINS = [
“http://localhost:5173“,
]

2.创建前端

1.在AIFriends/目录下执行：

npm create vue@latest

// 项目名称：frontend
// 包含的功能：Router、Pinia

然后

cd frontend
npm install（安装）
npm run dev（启动）

2.在AIFriends/frontend/vite.config.js文件中：

…
import path from ‘path’

export default defineConfig({
…
build: {
outDir: path.resolve(__dirname, ‘../backend/static/frontend’), // 打包到 Django static
emptyOutDir: true,
},
..
如果项目创建错了，删掉AIFriends/frontend文件夹，重新创建一遍即可。

3.合并前后端
在AIFriends/frontend/目录下执行npm run build， 可以将前端代码打包
将打包内容集成到后端，而不是生成dist文件夹了，而是在后端多一个static文件夹
